# Тема Дикси — примерка на Технолинке

Новая тема поверх текущего Vuetify 3, чтобы посмотреть старые экраны в новом стиле на тестовом стенде. Код экранов не трогаем, меняется только тема. Собрано на Vuetify 3.13.7.

## Что внутри

- `dixy-theme.js` — цвета, полупрозрачные переменные и настройки компонентов по умолчанию: кнопки-таблетки без капса, обведённые поля, без теней и ряби.
- `settings.scss` — SASS-переменные Vuetify: шрифт, шаг отступов, скругления, типографика, высота кнопок, полей и строк списка.

## Как подключить

1. Тема и defaults — в `createVuetify` вместо текущих. Если тема называется не `light`, подставить своё имя.

   ```js
   import { dixyTheme, dixyDefaults } from './dixy-theme'

   createVuetify({
     theme: { defaultTheme: 'light', themes: { light: dixyTheme } },
     defaults: dixyDefaults,
     // остальное как было
   })
   ```

2. SASS — через `vite-plugin-vuetify`. Без этого шрифт, скругления и размеры не применятся. Если `configFile` уже есть — перенести переменные в него.

   ```js
   vuetify({ styles: { configFile: 'src/styles/settings.scss' } })
   ```

3. Шрифт Moderustic, начертания 400, 500, 600 — с Google Fonts или локально.

   ```html
   <link href="https://fonts.googleapis.com/css2?family=Moderustic:wght@400;500;600&display=swap" rel="stylesheet">
   ```

## Цвета Технолинка → новые

| Имя | Было | Стало |
|---|---|---|
| `primary` | #8445D1 | #7300FF |
| `primary-light` | #EADDFF | #F2E8FF |
| `primary-dark` | #21005D | #21005D — аналога нет, оставлен |
| `accent` | #F07601 | #F2830C |
| `accent-light` | #FFF3E6 | #FEF4E9 |
| `surface` | #E8E5EB | #F2F3F5 — фон страницы |

Остальные цвета (`secondary`, статусы, текст, подложки) — из новой темы.

## Где может поехать

- **Локальные стили на экранах** — `color`, `rounded`, scoped-стили перекрывают тему. Такие места останутся в старом виде, по ним и видно, что придётся править руками.
- **`surface`** — компоненты, которые по умолчанию берут его как фон (карточки, списки), станут серыми. Белая карточка в новой теме — `surface-bright`.
- **`primary-dark`** — посмотреть, где используется, и решить, чем заменить.
- **Размеры** — шапка 72 px, кнопки и поля 48, строки списка 56. Может сдвинуть разметку.
